# h5n1-mammal-jump
Cross-cohort analysis of mammalian-adaptation mutations in H5N1 clade 2.3.4.4b.

## Slices
- pb1pa/ - Builder 2: PB1 + PA mutation enrichment analysis (mammalian vs avian isolates,
  2021-2026), positive-control validated, structural mapping onto the H5N1
  polymerase / human ANP32B complex (PDB 8R1J/8R1L). Gates: pb1pa/GATES.md
- pb2/ - Builder 1: PB2 analysis (owned separately)
